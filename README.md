# 💣 Python Minesweeper GUI Game

## 📌 Overview
A classic **Minesweeper** game implemented in Python using Object-Oriented Programming (OOP) principles and a Graphical User Interface (GUI) built with `tkinter`. 

The project features dynamic board generation, recursive cell revealing for empty areas, mine placement algorithms, flag positioning, and full game state checks (Win / Game Over).

## ✨ Features
* **Customizable Difficulty:** Player inputs board size and total bomb count dynamically.
* **Graphical User Interface (GUI):** Interactive board built with `tkinter` buttons.
* **Object-Oriented Architecture:** Clean separation of concerns into `Minesweeper`, `Board`, and `Cell` classes.
* **Recursive Reveal Algorithm:** Automatically reveals adjacent empty cells when a zero-adjacent-mine cell is clicked.
* **Flagging System:** Right-click interaction to flag suspected mine locations.

## 🛠️ Tech Stack & Concepts
* **Language:** Python 3.x
* **GUI Framework:** `tkinter`
* **Concepts:** OOP, Recursion, Event-Driven Programming, Data Structures (2D Arrays)
